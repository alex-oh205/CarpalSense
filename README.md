# CarpalSense

Wearable sensor project made by Alex Oh and Arjun ArunPrasad on the software side and Shiv Patel and Kanata Sasaki on the hardware side.

Hardware: A glove that detects and monitors carpal tunnel syndrome using flex sensors, EMG sensors, and an Arduino Nano.
Software: The CarpalSense website, containing detailed usage instructions and a real-time monitoring dashboard displaying the collected data.
