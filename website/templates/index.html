What is CarpalSense?

CarpalSense is a wearable sensor that can help prevent and manage carpal tunnel syndrome through live monitoring and data analytics.

How Does it Work?

CarpalSense works by using sensors to detect hand movements over time, providing immediate feedback to users if they are at risk.


Features


Real-time Detection

CarpalSense provides constant feedback about hand movements and positioning to prevent the onset of the condition.

Mathematical Modeling

CarpalSense uses a mathematical model to identify the point when the user is at risk of developing carpal tunnel.

Recommended Breaks

CarpalSense suggests users when to take a break so that they have a minimal risk injuring themselves.
